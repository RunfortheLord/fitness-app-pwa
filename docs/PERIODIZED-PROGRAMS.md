# Asymmetrical weeks

In Training, open the program editor and turn on **Asymmetrical weeks** in Settings. Ordinary programs start with the switch off. Enabling it starts each week with the program's existing days and exercises. The editor keeps its usual day tabs. Select a training week before adding, removing, reordering or editing an exercise.

**Week options** can rename the week, change the start date, or copy the whole week to selected destinations. Copying replaces the destination weeks' prescriptions, week names and day assignments. Exercise and set edits save automatically to the displayed week. To copy the edits made since opening that exercise, expand **Apply edits to other weeks**, choose the destinations and tap **Apply to selected weeks**. Program name and length are under **Program details**.

## Loads and workout logging

Each set group has a type, set count, rep range, RIR, rest and weight target. Choose **Fixed weight** or **Percentage of 1RM**. A percentage uses the saved maximum of the selected reference lift and rounds to the nearest increment for the exercise being performed. Save a lift's 1RM in the exercise editor. It is shared across programs, including programs using another lift as their reference. A missing maximum leaves the calculated load empty. Performance logs and program reference estimates never write a saved maximum.

Choose the week and start the workout day manually in Training. The February program initially displays the calendar week. A manual selection persists until changed. Each workout snapshots the targets at its start. Subsequent program or maximum edits affect future starts. Actual results stay separate from targets, and completed history retains its original prescriptions. Live exercise tabs, swiping, timers and logging controls work as usual. Set groups have short labels for warm-ups, top sets, back-offs and max attempts.

## February 2027 peak

The program library contains **February 2027 Powerlifting Peak + Upper Body Hypertrophy**, with asymmetrical weeks enabled on a fresh install. Its 14 weeks start November 23, 2026 and end February 28, 2027. Week 1 is Deload, weeks 2–5 are Volume, weeks 6–8 develop strength, weeks 9–11 are Intensification, week 12 is Peaking, week 13 is Taper and week 14 is Max testing. Test-week workouts are bench on February 22, squat on February 24 and sumo deadlift on February 27.

Existing deload scheduling stays available in Settings. A manually scheduled deload uses the ordinary one-set reduction and adds three target RIR. February's Deload and Taper weeks have their own reduced prescriptions and receive those reductions only once. Recovery sessions stay in History and are excluded from progression comparisons.

## Compatibility

Database version 23 adds week names, explicit load modes and an optional saved maximum on each exercise. Legacy defaults and phase/week overrides retain their keys and continue to resolve the program's original prescriptions. A previously explicit on/off choice is preserved. The supplied February template takes its new default when its old flag was absent. Other existing programs and active cycles keep their prior opt-in behavior. Backup import also upgrades legacy program data. Historical sets and in-progress workout snapshots are preserved.
